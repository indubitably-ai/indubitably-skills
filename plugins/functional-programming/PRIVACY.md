# Functional Programming Privacy Policy

Effective date: October 1, 2026.

Functional Programming is an open-source functional-programming plugin published by Gregory George Pazo and maintained in the [Indubitably skills repository](https://github.com/indubitably-ai/indubitably-skills). This policy describes the plugin package and its support channel.

## Plugin data handling

The plugin contains instructions, reference documents, and visual assets. It has no MCP server, connector, publisher-operated backend, account system, telemetry, advertising, or analytics code. The package does not send your prompts, source code, repository files, or conversation history to the publisher. The publisher does not receive or store that information through the plugin.

The plugin provides guidance to the AI host, which may use tools available in your session to inspect or modify code when you request that work. Tool access, permissions, execution, and storage are controlled by the host and any services you connect. Installing the plugin does not create a separate connection to the publisher.

## ChatGPT, Codex, and other services

Your AI host processes the information you provide to it under its own privacy policy, account settings, and applicable agreements. This policy does not replace those policies or describe their retention practices. Likewise, GitHub handles visits, downloads, and account activity under its own policies. The plugin includes links to documentation; opening a link uses the destination service.

## Support and voluntary disclosures

Support is available through the repository's [GitHub issue tracker](https://github.com/indubitably-ai/indubitably-skills/issues). If you open an issue, the information you choose to post is visible to the maintainers and the public. Maintainers use it to answer questions, investigate bugs, and improve the plugin. Do not include secrets, private source code, or personal information in public issues. GitHub controls the storage of these posts, and you can use GitHub's controls or support channels to manage your contributions.

## Questions and changes

For questions about this policy, open an issue without including sensitive information. Changes to the plugin's data handling will be documented here with an updated effective date. Previous versions remain available in the repository history.
